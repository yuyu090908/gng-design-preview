# GLOBAL NIGHT GUIDE（オリジナルデザイン版）

グローバルナイトガイドの記事を、オリジナルデザインの静的サイトとして Vercel で公開するためのリポジトリです。

- 記事・カテゴリ・固定ページは、ビルド時に本番 WordPress の REST API（`/wp-json/wp/v2/`）から取得します。
- サイト内のリンクはすべてこのサイトの中で完結します（記事内の本番サイトへのリンクも、このサイトのページに書き換えます）。行き先がこのサイトに無いリンク（タグページなど）はリンクを外します。
- 画像は本番サイトのものを表示しています。

## 作られるページ

| パス | 内容 |
| --- | --- |
| `/` | トップ（エリア・ランキング・新着・国内／海外） |
| `/page/2/` 〜 | 新着記事の一覧 |
| `/category/〇〇/` | カテゴリごとの記事一覧（12 件ずつ） |
| `/<記事ID>/` | 各記事（目次・関連記事・前後の記事つき） |
| `/about/` `/contact/` など | 固定ページ |
| `/search/` | サイト内検索 |

## 編集のしかた

- デザイン：`src/site.css`（スマホ基本、768px・1100px 以上で拡張）
- 動き（メニュー・目次・検索）：`src/site.js`
- ページの組み立て：`build.mjs`

`main` に push すると Vercel が自動でビルドし直します。本番で記事を更新したときは、Vercel の「Redeploy」で最新の記事が反映されます。

## 手元で確認する

```
npm install
npm run build        # 本番から取得（ネットワークが必要）
```
